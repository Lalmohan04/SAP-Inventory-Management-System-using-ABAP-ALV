# Project Documentation

This directory contains the project report, ABAP code evidence, architecture documentation, data-flow documentation, and data-model documentation for the SAP Inventory Management System.

## Documentation Files

| File | Description |
|---|---|
| [`Inventory_Management_System_Report.pdf`](Inventory_Management_System_Report.pdf) | Complete 30-page project report covering the project objectives, methodology, architecture, implementation, results, and future scope. |
| [`Internship_Evaluation_Poster.pdf`](Internship_Evaluation_Poster.pdf) | Internship evaluation poster summarizing the project and its key results. |
| [`SAP-IMS-Code-Screenshots.docx`](SAP-IMS-Code-Screenshots.docx) | Supplied document containing the ABAP code screenshots used as implementation evidence. |
| [`architecture.md`](architecture.md) | Detailed explanation of the three-layer system architecture. |
| [`data-flow.md`](data-flow.md) | Detailed explanation of the end-to-end inventory data flow. |
| [`data-model.md`](data-model.md) | Documentation of the SAP tables, ABAP structures, fields, and relationships used by the system. |
